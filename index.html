Configurações

Impressoras

Impressoras do computador do robô (DP002). Podem ser a mesma.

Imprimir neste computador

Para quando a impressora fica perto do caixa e longe do robô. Vale só para este navegador.

Para sair sem a janela de impressão, abra o Chrome com a opção --kiosk-printing (o LEIA-ME explica).

Agentes de impressão

Programa instalado no computador do caixa que imprime sozinho, na impressora escolhida para cada tipo. Se usar o agente, desmarque as opções acima para não imprimir duas vezes.

Fechamentos

Reimprima o relatório do app ou o fechamento do EVO de turnos anteriores.
